# Student Grade Tracker
A lightweight CLI Python application designed to manage student academic records, including grades and attendance, with JSON storage.

## Features
* **Interactive CLI Menu:** Easy-to-use text interface.
* **Formatted Output:** Displays student data in an aligned table layout using `f-strings`.
* **JSON Persistence:** Automatically saves and loads student data across sessions.
* **Input Validation:** Built-in `try/except` error handling to prevent invalid entries.

## Tech Stack
* **Language:** Python 3
* **Libraries:** `json`, `os` (built-in)
